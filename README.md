# homebrew-tap

Homebrew formulae for my projects.

```sh
brew install imrajyavardhan12/tap/<formula>
```

| Formula | Install | What it is |
|---|---|---|
| [ripe](https://github.com/imrajyavardhan12/ripe) | `brew install imrajyavardhan12/tap/ripe` | See and update every outdated app on your Mac: Homebrew, App Store and direct downloads |
| [margin](https://github.com/imrajyavardhan12/Margin) | `brew install imrajyavardhan12/tap/margin` | A fast, keyboard-first terminal diff viewer for Git changes, patches and AI-authored code |

Formulae are updated automatically by each project's release workflow. Upgrade with `brew upgrade`.
